# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good faith, critique work rather than people, and help keep discussion welcoming
to newcomers.

Report unacceptable behaviour to the maintainer at arnavkapoor23@iiserb.ac.in. Reports are handled confidentially.
